# وثيقة شاشة التحميل والبدء — `splash/` (Souqi Splash Module)

> **المسار:** `splash/`  
> **الإصدار:** 2.1 (الهوية الصفراء الأيقونية وثبات اللون عبر كافّة الأوضاع)  
> **الحالة:** مكتمل ومدمج مع موجه التطبيق بنسبة 100%

---

## 1. نظرة عامة والمعمارية (Architecture)

شاشة البدء هي نقطة الدخول الترحيبية لتطبيق سوقي (Souqi Mini App) على تيليجرام. صُممت لتقديم انطباع أول فخم وعصري مستوحى من كبرى المنصات العالمية، بالاعتماد الكامل على **اللون الأصفر الكهربائي الساطع (`#FFD200`)** مع مجسم الشعار ثلاثي الأبعاد والخط الفاصل الأسود الصريح.

```text
splash/
├── index.html       # هيكل الشعار المجسم، العناوين، وشريط تقدم التحميل
├── style.css        # التنسيقات البصرية والظلال ثلاثية الأبعاد والانتقالات الحركية
├── script.js        # دورة حياة التهيئة والمصافحة مع Telegram WebApp SDK
└── README.md        # هذه الوثيقة الفنية المرجعية
```

---

## 2. المكونات البصرية الأساسية

1. **الخلفية الصفراء الأيقونية (`.splash-screen.signature-yellow`):**
   - تعتمد دائماً على اللون الأصفر الساطع المعتمد (`#FFD200`).
   - تم تأمينها بنظام التوكنات لتبقى ثابتة ومشرقة في كلا الوضعين (الليلي والأبيض الحليبي) دون أي تأثر.

2. **الشعار ثلاثي الأبعاد المائل (`.splash-3d-badge`):**
   - مجسم أسود كربوني فخم (`#121214`) بزوايا دائرية منحنية (`border-radius: 34px`).
   - تأثير دوران وميلان فيزيائي (`transform: rotate(-6deg) skewX(-2deg)`).
   - ظلال عميقة متعددة الطبقات مع إضاءة حواف داخلية دقيقة (`inset shadow`).
   - النص الإنجليزي باللون الأصفر الساطع المضيء (`SOUQI`) متبوعاً بالنص العربي الموثق (`سوقي`).

3. **الخط الفاصل والعبارات الترويجية:**
   - فاصل أسود مستدير أنيق (`.splash-divider`).
   - العنوان الإنجليزي: `THE BIGGEST MARKETPLACE`.
   - العنوان العربي: `المنصة الأكبر لتداول القنوات والحسابات`.

4. **شريط التقدم ومؤشر الحالة (`.splash-bottom-bar`):**
   - مسار أفقي ناعم شبه شفاف (`.splash-progress-track`).
   - شريط تقدم أسود متحرك بانسيابية (`.splash-progress-bar`).
   - نقطة حالة نابضة بالحركة (`.splash-status-dot`) مع نصوص حالة حية تتغير تدريجياً:
     - `جاري التحقق من بيانات تيليجرام... (25%)`
     - `جاري مزامنة الحساب والبيانات... (65%)`
     - `جاهز للانطلاق! (100%)`

## 3. التكامل مع Telegram WebApp SDK وموجه التطبيق

- **المصافحة الأولية (Handshake):**
  - استدعاء `Telegram.WebApp.ready()` فور التحميل.
  - استدعاء `Telegram.WebApp.expand()` لفتح الشاشة بكامل حجم نافذة تيليجرام.
  - صبغ ترويسة وخلفية تيليجرام العلوية بلون الشاشة الأصفر الساطع (`#FFD200`) لضمان عدم ظهور أي حواف أو فواصل لونية غير متجانسة أثناء التحميل:
    ```javascript
    tg.setHeaderColor?.('#FFD200');
    tg.setBackgroundColor?.('#FFD200');
    ```
- **الانتقال السلس (Seamless Exit Transition):**
  - بعد اكتمال التحميل بنسبة 100%، يضاف كلاس `.fade-out` لتتلاشى الشاشة بنعومة مع تصغير دقيق (`transform: scale(0.98)`).
  - يتم استدعاء رد النداء `onComplete()` الذي يقوم بكشف شاشة السوق في الخلفية فوراً وتعديل ألوان ترويسة تيليجرام لتناسب المظهر المعتمد (الداكن `#121214` أو الحليبي `#F5F7FA`).

## 4. التكامل مع الباك إند (`باك اند.docx`)

| المرحلة | الاستدعاء المستهدف | الغرض |
|---|---|---|
| **التحقق من الهوية** | استخراج `Telegram.WebApp.initData` | المصادقة الأمنية المشفرة وتوقيع HMAC |
| **مزامنة الحساب** | `POST /api/auth/telegram-sync` | تسجيل المستخدم تلقائياً وجلب الجلسة الحالية |
| **فحص الرصيد** | `GET /api/app/session` | تهيئة بيانات الرصيد والألماسات في الخلفية |
