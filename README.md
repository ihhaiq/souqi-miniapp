# سوقي — تطبيق تيليجرام المصغر (Souqi Mini App)
## الواجهة الأمامية المعمارية (Branch: `webapp`)

هذا المستودع يحتوي على الواجهة الأمامية الكاملة لتطبيق **سوقي** (منصة تداول الحسابات والقنوات الرقمية والوساطة الموثقة عبر Telegram Mini App).

## 1. المعمارية العامة ومبدأ العمل (Architecture)

يعتمد المشروع نمط **الموديولات المعيارية المستقلة (Modular Page Architecture)** ضمن إطار تطبيق صفحة واحدة (Single Page Application - SPA) فائق الأداء ملائم لبيئة تيليجرام وتطبيقات الويب الحديثة:

```text
front end/
├── index.html               # الحاوية الرئيسية ومحددات نظام التصميم المزدوج (App Shell)
├── app.js                   # الموجه، محرك المظهر، ومدير دورة الحياة (Router & State Orchestrator)
├── system_design.md         # نظام التصميم المعتمد وجدول التوكنات البصرية
├── README.md                # الوثيقة الفنية المركزية للمشروع
├── باك اند.docx             # المرجع الفني الرسمي لعقود وتفاصيل الـ API
├── old V/                   # الأكواد والملفات والتصاميم السابقة كمرجع تاريخي
├── splash/                  # شاشة التحميل والبدء (Module 1)
│   ├── index.html           # هيكل الشعار المجسم والعبارات الترويجية
│   ├── style.css            # تنسيقات الهوية الصفراء الأيقونية والظلال 3D
│   ├── script.js            # دورة حياة التهيئة والمصافحة مع Telegram SDK
│   └── README.md            # التوثيق التفصيلي لشاشة البدء
├── market/                  # شاشة السوق وتصفح العروض (Module 2)
│   ├── index.html           # شريط الكبسولة، البحث، الفلاتر، وشبكة المنتجات
│   ├── style.css            # التنسيقات، التكيف الشامل، والوضع الفاتح
│   ├── script.js            # الفلترة الحية، إيماءات السحب واللمس، وإدارة السلة
│   └── README.md            # التوثيق التفصيلي لشاشة السوق
└── account/                 # شاشة حسابي والملف الشخصي (Module 3)
    ├── index.html           # الملف الشخصي، الإحصائيات، الكروت المزدوجة، والقوائم
    ├── style.css            # أنماط الأيقونات الأحادية، وثيم الأبيض الحليبي
    ├── script.js            # مزامنة تيليجرام، وتعديل الاسم، وتبديل المظهر
    └── README.md            # التوثيق التفصيلي لشاشة حسابي
```

## 2. نظام المظهر المزدوج (Dual Theme Engine)

تم تطبيق نظام مظهر متكامل يتم التحكم فيه عالمياً عبر `window.App.toggleTheme()` وتخزينه في `localStorage`:

1. **الوضع الداكن الكربوني (Dark Carbon Theme):**
   - أسطح كربونية متعددة الطبقات (`#121214` و `#1C1D21` و `#222328`) مصممة خصيصاً لشاشات OLED لمنع إجهاد العين وتقديم فخامة بصرية عالية.
2. **الوضع الأبيض الحليبي (Milky White Theme):**
   - أسطح حليبية نقية ناعمة (`#F5F7FA` و `#FFFFFF` و `#F8FAFC`) مع حدود رقيقة `#E2E8F0` ونصوص كربونية عالية التباين `#0F172A`.
   - تحول كبسولة التصنيفات وزر السلة إلى اللون الأبيض الناصع، مع بطاقة نشطة كربونية فخمة.
   - تحول خلفيات أغلفة كافة المنتجات الـ 16 إلى درجات حليبية ناعمة `#F1F4F9` مع التلاشي الضوئي.
3. **ثبات الهوية باللون الأصفر الساطع (`#FFD200`):**
   - اللون الأصفر الكهربائي الساطع (`--accent-yellow: #FFD200`) ثابت وموحد عبر كامل النظام في كلا الوضعين.
   - شاشة التحميل (Splash Screen) تفتح دائماً باللون الأصفر الساطع الأصلي.
   - الأزرار الأساسية (مثل زر "أوافق وأفهم الشروط" وزر تطبيق الفلتر) تحتفظ باللون الأصفر مع نصوص سوداء واضحة `#121214`.

## 3. التكيف الشامل وتأطير الشاشات (Universal Responsiveness)

- **على الهواتف الذكية (`<= 480px`):** امتداد كامل بنسبة 100% مع الالتزام التام بمناطق الأمان (Safe Areas) لتيليجرام وهواتف iPhone الحديثة.
- **على الشاشات العريضة والحاسوب (`> 480px`):** تتمركز الواجهة في المنتصف كإطار هاتف ذكي أنيق بعرض أقصى `max-width: 480px` مع حدود رقيقة وظل ناعم، مما يضمن ثبات تجربة الاستخدام عند التكبير أو فتح الرابط على Telegram Desktop/Web.
